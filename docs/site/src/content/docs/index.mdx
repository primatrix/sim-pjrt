## 当前定位

这是一个单主机的执行与性能建模实验项目。浮点计算使用占位结果，性能参数尚未经过真实 TPU 校准；适合研究执行路径、依赖与成本假设。已用 dummy 权重运行过 Llama 和 Qwen3 MoE 的 serving 流程，覆盖范围与验证状态见[当前限制](/reference/limitations/)。

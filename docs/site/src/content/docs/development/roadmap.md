当前支持 libtpu → bundles 计时、CPU 输出模拟、Virtual HBM 和原生 XProf，以及真实 TPU profile 离线导入和可选的精确耗时回放。

## P0：计时准确性与真机验证

### 真实 TPU 基准与校准

已有单设备 7B 真机基准，测量配置和已记录的结果见仓库的 `docs/benchmark.md`。继续验证未参与校准的 shape、拓扑及 serving 工作负载，记录配置并公布误差。

CPU wall-clock 不能作为 TPU 观测值。只有可辨识的参数才能拟合，覆盖 compute-bound 内核并不能独立确定 HBM 带宽。

目前已完成操作耗时采集、元数据解析和兼容计算结构分组，尚未实现曲线拟合或新 shape 的耗时预测。
